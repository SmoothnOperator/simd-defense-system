INSIGHT 1: STARTUP AMORTISATION CURVE

For small arrays (n < 3), Scalar Processor wins because Vector pipelining startup (12 cycles) is not yet amortized. As n reaches 64, speedup hits peak (4.21×). Notice the strip-mining sawtooth at n = 65 where a second 12-cycle chunk startup is incurred.

INSIGHT 2: AMDAHL'S LAW SERIAL BOTTLENECK

Formula: S(f) = 1 / ((1 - f) + f / P). Even with an infinite supercomputer (P → ∞), if 10% of code is sequential (f = 90%), total speedup is strictly capped at 1 / 0.10 = 10×. The serial fraction always dominates total execution time.

INSIGHT 3: ROOFLINE MODEL BOUNDARY

Attainable GFLOP/s = min(Peak Compute, Arithmetic Intensity × Memory Bandwidth). To the left of the knee (1.5 FLOP/B), performance is bounded by DRAM bandwidth (Memory Bound). To the right, SIMD execution units saturate peak performance (Compute Bound).
